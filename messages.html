How this is built, and what the badges mean
Where the messages come from

The corpus is scraped from the You feel and You hear wiki pages by scripts/gen-messages.py, which parses each page's {{message|text|explanation}} templates. That gives the message text, its wiki-written explanation, and every wikilink inside that explanation.

Every one of those wiki-sourced messages was then handed to a fleet of subagents that grepped the actual NetHack-3.7 and NetHack-5.0 branches for the literal C string that produces it, recording the exact file:line when found. A second sweep went the other direction: it read every You_feel()/You_hear() call site in 5.0's source and flagged ones that don't correspond to any wiki-documented message at all — those are marked “5.0-only, not on the wiki”.

That reverse sweep can only speak for 5.0, so a final deterministic pass in gen-messages.py closes the gap: once a call site is known in 5.0, its exact C string literal is known too, and looking that literal up in the 3.7 tree is a plain search rather than an open-ended read. Where the same literal appears at several call sites, the one in the same file and nearest the 5.0 line wins; where it's ambiguous across files, the entry is left unverified rather than guessed at. That pass resolves 188 of the 190 sweep entries against 3.7.

What the version badges mean

present — a source line producing this exact text was found in that branch; the file:line and literal C string are shown. absent — the wiki's wording was searched for and not found; the closest source text found instead is noted, in case the wiki is simply out of date rather than wrong. unverified — the search was inconclusive, not that the message is known to be missing: the call site is built entirely from format strings (You_feel("%s!", abil->gainstr) carries no literal to look up), or the literal it does carry appears at too many call sites to pick one. Unverified means unknown, and only five entries are still in that state.

Search scope

Matches the message text and its explanation, not the source file paths or literal C strings. Punctuation is ignored on both sides, so “can't” and “cant” find the same rows.
